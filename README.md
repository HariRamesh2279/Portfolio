# Personal Portfolio Website

This project is a concise responsive portfolio focused on:

- About Me
- Skills
- Contact details

## Files

- `index.html` – Portfolio page structure
- `style.css` – Responsive styling and modern UI
- `script.js` – Theme toggle, mobile menu, and contact form behavior

## Run Locally

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
